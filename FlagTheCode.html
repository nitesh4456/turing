FLAG THE CODE

About Falg The Code

Flag the Code is a technical Bug Hunt competition where participants analyze a deliberately vulnerable website to identify bugs, hidden flaws, and security issues. Teams must explore the website, inspect its code, and report the discovered bugs within the given time limit. The team that successfully identifies the maximum valid bugs with proper explanation will be declared the winner.

Rules & Guidelines

  • Participation will be in teams of 2 members.
  • Each team will be provided access to a demo website containing intentional bugs.
  • Participants must identify bugs such as hidden data, broken authentication, validation errors, or security vulnerabilities.
  • Bugs must be submitted through the Google Form submission portal provided by the organizers.
  • Each bug must include location, bug type, and explanation.
  • Participants are allowed to use browser developer tools (Inspect Element, Console, Network tools).
  • The use of external hacking tools or attacking real systems is strictly prohibited.

Format & Winning Criteria

Format

  • The competition will be conducted in a single round bug hunting format.
  • Teams will be given access to a buggy website with multiple pages containing hidden bugs and vulnerabilities.
  • The event duration will be 90–120 minutes.

Device & Connectivity

  • Participants must bring their own laptops.
  • Requirements:
    • Laptop with web browser
    • Internet access (WiFi provided by organizers)
    • Ability to use browser developer tools
  • No special software installation is required

Scoring System

  • Points will be awarded based on the difficulty of the bug discovered.
    • Easy Bug - 50 points
    • Medium Bug - 100 points
    • Advanced Bug - 200 points

Winning Criteria

  • The team with the highest total score at the end of the competition will be declared the winner.
  • In case of a tie:
    • The team that discovered the highest difficulty bug will be ranked higher.
    • If still tied, the earliest submission time will be considered.

Disqualification Criteria

  • Participants will be disqualified if they:
    • Attempt to attack or modify systems outside the provided demo website.
    • Share answers with other teams.
    • Tamper with the website or event infrastructure.
    • Use automated vulnerability scanners or hacking software not permitted by organizers.
    • Engage in any unfair or unethical activity during the competition.

Note

  • Participants are encouraged to bring their own laptops with a modern web browser (Chrome/Firefox).
  • Basic knowledge of HTML, JavaScript, and web security concepts may be helpful but is not mandatory.
